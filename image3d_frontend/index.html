使用说明

最快操作流程
  1. 上传清晰的参考图
  2. 生成并检查正、左、右、背视图
  3. 点击“确认四个视角”
  4. 保持“仅几何白模”并提交
  5. 预览并下载 STL
1. 图片要求
  • 使用单一主体、轮廓完整、接近正面的图片。
  • 背景尽量简单，避免大面积遮挡或裁切。
  • 支持 PNG、JPEG、WebP，单张不超过 4 MB。
  • 明显的侧面、背面或顶部图片会被要求更换。
2. AI 自动生成视图
  1. 选择一张正面主图。
  2. 补充视角来源保持“AI 自动生成”。
  3. 按需填写补充要求。
  4. 点击“生成正、左、右、背四视图”。

系统会根据参考图重新生成正、左、右、背四视图。AI 分析和四张图片生成都会产生模型调用费用。

3. 自己上传视图

当前手动模式需要四张输入图片：

  • 正面主图
  • 左视图
  • 右视图
  • 背视图

此模式不会调用 GPT 分析或生成图片，但生成 STL 仍会调用腾讯混元。

4. 检查和确认
  • 点击图片可以打开大图检查。
  • 检查零件数量、比例、颜色和标识是否一致。
  • AI 结果可逐张“微调”；手动图片可逐张“替换”。
  • 修改主体描述后，需要重新生成对应视图。

确认无误后点击“确认四个视角”，按钮会显示“已确认 ✓”。

5. 生成、预览和下载 STL
  • 只需要几何结构时，保持默认“仅几何白模”。
  • 点击“提交 STL 任务”后等待腾讯混元完成。
  • 页面会显示任务状态、等待时间和任务编号。
  • 完成后可拖动预览模型，滚轮缩放，然后下载 STL。
6. 常见问题

按钮不能点击

检查上一步是否完成。正、左、右、背四视图齐全并确认后，才能提交 STL。

一直显示处理中

查看步骤状态和错误卡片；网络中断时可点击“立即刷新”。超时任务会自动解除锁定。

腾讯混元提交失败

检查 API Key、余额、模型名、接口地址和 Vercel Blob。反馈问题时请一并提供错误编号和 Request ID。

刷新后任务是否还在

同一标签页刷新可以继续；关闭标签页后不会自动恢复上一次内容。

生成图片和 STL 都可能产生供应商费用，请避免重复提交。
